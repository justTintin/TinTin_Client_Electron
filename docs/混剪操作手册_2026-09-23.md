# 混剪操作手册（智能混剪 / 文案混剪）

| 项目 | 内容 |
| --- | --- |
| 文档版本 | v1.0（2026-09-23） |
| 适用产品 | 螺丝钉-电商智能体矩阵 客户端（Electron 桌面端） |
| 适用模块 | 媒体工具 →「智能混剪（视频分组）」、「文案混剪」 |
| 目标读者 | 使用混剪功能产出短视频/剪映草稿的操作人员 |
| 维护约定 | 流程或目录变更时同步更新本文档；涉及服务端接口的描述以实测为准 |

---

## 1. 功能定位

| 模块 | 定位 | 交付形态 |
| --- | --- | --- |
| 智能混剪 | 从已有视频素材出发：分割镜头 → 镜头重组出多条成片 → 逐条配音 → 特效包装 | 成片视频（服务端合成/本地合成）或剪映草稿 |
| 文案混剪 | 从文案出发：先有文案与分镜 → 克隆整段旁白 → 按分镜匹配素材 → 虚拟时间轴方案 | **剪映草稿**（唯一交付形态） |

两条流程相互独立，可单独使用；命名上前缀 `copywriting-montage`（文案混剪）与 `montage`（智能混剪）仅用于代码模块区分，界面入口均位于「媒体工具」页。

## 2. 前置条件

### 2.1 环境与服务

| 项 | 要求 | 说明 |
| --- | --- | --- |
| 服务端 | 已配置且在线 | 顶栏状态灯显示「服务端正常」；地址在「设置」页可改（默认 `http://192.168.111.31:8000`）。声音克隆、镜头分割、字幕对齐、素材/音效/模板库均依赖服务端 |
| GPU 服务 | whisperx（字幕对齐）、TTS（克隆合成）已加载 | 服务端繁忙时单条合成耗时明显增加，批量任务支持中途停止 |
| ffmpeg | 随客户端资源分发（`resources/bin`，Git LFS） | 拉取代码后需执行 `git lfs pull`，缺失会导致 ffprobe 调用失败 |
| 剪映专业版 | 已安装并登录（导出剪映草稿/音频自动同步需要） | 草稿导出写入剪映草稿箱目录 |
| 缓存目录 | 已在「设置」页配置 | 所有过程资产落在该目录下（见 §5），建议预留 ≥10GB |

### 2.2 素材要求

| 素材 | 格式 | 建议 |
| --- | --- | --- |
| 视频素材 | mp4 / mov / avi / mkv / flv / webm / m4v | 竖屏优先（文案混剪默认输出 1080×1920）；单个素材 ≥ 最小镜头时长 |
| 音频样本（声音克隆） | wav / mp3 / m4a / flac / aac / ogg | 时长适中、人声清晰、底噪小；可填写对应文字提高克隆质量 |
| 产品资料 | 在「产品库」维护，含**关联关键词** | 关键词命中、口播文案生成、分镜生成都依赖产品信息；未关联关键词时由 LLM 兜底提取 |

### 2.3 客户端配置

- 参考声音：服务端「声音样本库」中已有样本，或在界面底部现场上传（上传后自动选中）。
- TTS 引擎：默认 QwenTTS（qwen3），可切 IndexTTS；IndexTTS 支持语速/情感/句间停顿参数，QwenTTS 用指令文本描述语气语速。
- 文字模板 / 花字 / 字幕样式 / LUT / 音效库：服务端库内需先有内容（服务端离线时相关列表为空或走本地兜底）。

## 3. 智能混剪操作流程

> 入口：媒体工具 → 智能混剪（视频分组）。步骤条：①素材 ②镜头重组 ③口播配音 ④特效包装。

### 3.1 第①步 素材与镜头分割

1. 点击「添加视频」或「选择文件夹」（自动遍历子文件夹）加入原始视频。
2. 设置分割参数（分割阈值、最小镜头秒数——参数影响切分粒度，一般保持默认）。
3. 点击「开始智能镜头分割」。服务端完成切分与逐镜分析后，分割片段自动批量缓存到本地（进度逐素材推进）。
4. 支持「停止分割」：当前素材完成后停止，已完成素材保留（淡绿标识），再点开始只补未完成的（断点续分）。

### 3.2 第②步 预合成列表（镜头重组）

1. 在镜头列表勾选参与合成的镜头（评分过滤可辅助）。
2. 点击「镜头重组」生成**预合成列表**（每行一条成片方案）。
3. 每行支持：
   - 单击选中、双击查看口播文案全文；
   - **右键菜单**（按方案状态自动切换首项）：
     - 待确认方案 → 「完成：确认合成视频」；
     - 已合成方案 → 「**重启合成**」（重置确认态后重新提交合成，镜头与文案不变）；
     - 「生成口播文案」（弹窗内可选产品库条目自动填充）；
     - 「查看文案」（已生成口播文案时显示）；
     - 「删除预合成视频」（红色危险项，从列表移除该条）。
4. 右下角镜头详情表支持拖动调序、右键标记删除/恢复（不参与合成与预览）。

### 3.3 第③步 口播配音

1. 「参考声音」下拉选择服务端声音样本（播放条可试听；样本会自动带出参考文案）；没有合适样本时在页尾上传新音频创建。
2. 选择 TTS 引擎；「设置声音克隆」中按引擎调整语速/情感/句间停顿（QwenTTS 为指令文本）。
3. 点击「开始批量克隆人声合成」。批量任务为**串行逐条合成**，进行中可点「**停止克隆**」：当前条合成完成后停止，剩余条保持待合成。
4. 再次点击「开始批量克隆」即**从断点续跑**（自动跳过已生成条目）；单条重做用该行「重新生成」。
5. 克隆完成后进入第④步；如需一键合成，第④步会自动先配音再特效。

### 3.4 第④步 特效包装与交付

1. 字幕：勾选「添加字幕」，选服务端字幕样式/字体/背景/动画（字幕时间来自服务端字级对齐，预览与成片一致）。
2. 花字：按需开启并选样式/位置。
3. 文字模板（关键词动画）：
   - 开启后每条成片按**关键词命中**渲染文字模板动画；
   - 词表优先级 = **手工标注 → 产品关联词 → LLM 补足（保证至少 3 词）**；
   - 关键词标注面板（时间轴条带位置）：每条视频一块字幕文本，带时间戳与字级对齐；**命中词彩色显示；选中文字右键「标注为关键词」；右键彩色词「取消标注」**；手工标注持久化，导出效果与自动命中一致。
4. BGM：全局或逐行指派（可从素材库/AI 生成）。
5. 交付：点「导出到剪映时间轴」生成剪映草稿（推荐）；「服务端合成」如为置灰表示暂时停用。导出完成后有逐轨完整性报告（视频/口播/字幕/文字模板/花字/BGM/音效）。

## 4. 文案混剪操作流程

> 入口：媒体工具 → 文案混剪。步骤条：①文案编写 ②视频素材 ③口播配音 ④特效包装。核心思路：**先文案 → 再声音 → 再按分镜匹配素材**。

### 4.1 第①步 文案编写与分镜

1. 「选择产品」从产品库带出品牌/产品/型号与关联关键词。
2. 高级设置中选场景与建议时长，点击「✨AI 生成视频文案」（也可手输）；文案编辑框与**当前激活的分镜脚本 tab** 绑定。
3. 点击「✨AI 生成分镜」由文案生成分镜卡（镜别/时长/画面/旁白/音效建议）；也可「选择脚本」从脚本库应用，或「保存脚本」入库（多脚本以 tab 切换，脚本自动同步服务端脚本库）。

### 4.2 第②步 视频素材与智能匹配

1. 点击「选择素材」打开素材弹窗（左右两栏，1:1）：
   - 左栏素材来源：**本地上传**（拖入文件夹→智能镜头分割，参数含最小镜头秒/分镜头时长）、**素材库**（类型过滤：视频/图片/全部；搜索/品牌/型号/分类；勾选后「加入素材池」）、在线搜索/AI 生成/混合（占位）；
   - 右栏**选择池**：所有来源的片段统一入池，每条带缩略图/时长/景别/评分，支持删除与 **MD5 内容判重标注**（重复条目琥珀色标记）。
2. 确认（「选择完成，开始智能镜头分割」）后弹窗关闭并自动分割；主界面「选择池」常显条同步展示池内容。
3. 点击「**智能匹配到分镜脚本**」→ 在弹窗中勾选要匹配的分镜脚本（默认全选）→ 确认后按各镜的景别/时长/画面语义从池中匹配装填（LLM 精选 + 循环兜底），分配结果见顶部分镜卡。
4. 视频设置（输出画幅/时长限制/转场动画/输出帧率）**按激活分镜 tab 各自保存**，切 tab 即切配置。
5. 点击「生成剪辑方案」（所有分镜绑定齐全才可点）：生成虚拟时间轴方案并同步脚本库。

### 4.3 第③步 口播配音

与智能混剪 §3.3 相同：选样本 → 选引擎 → 批量克隆（每分镜脚本一条整段旁白；支持停止/断点续跑）。时长限制自动跟随本分镜声音时长。

### 4.4 第④步 特效包装与交付（剪映草稿）

1. 字幕（服务端对齐 SRT）/花字/文字模板（含**关键词标注面板**，与智能混剪同款）/BGM（全局/逐行/素材库）。
2. 音效：目前「AI 音效包装」停用；可用「智能音效匹配」从服务端音效库按每镜音效建议自动匹配，单镜可重新生成。
3. 点击「导出剪映时间轴」生成剪映草稿；导出完成后有逐轨完整性报告。**文案混剪不渲染成片 mp4，剪映草稿即最终交付。**

## 5. 资产生成目录说明

所有过程资产落在「设置 → 缓存目录」（下文记作 `<缓存目录>`，示例 `D:\资产输出`）与其推导目录下。

| 路径 | 内容 | 生成时机 |
| --- | --- | --- |
| `<缓存目录>\montage_cache\<任务ID>\splits\<素材名>\*.mp4` | 智能镜头分割片段（服务端切分结果本地缓存） | 第①/②步分割完成后自动批量下载 |
| `<缓存目录>\montage_cache\session\lib\*.mp4` | 分割片段兜底缓存（任务 ID 尚未生成时的会话目录） | 同上（兜底路径） |
| `<缓存目录>\montage_cache\session\outputs\` | 兜底成片输出目录 | 合成时任务 ID 缺失的兜底场景 |
| `<素材父目录>\outputs\` | **成片输出目录**（推导规则：取素材路径中任一级 `outputs`；无则取素材父目录 + `\outputs`） | 智能混剪确认合成/服务端合成 |
| `<成片输出目录>\dubbed\*.mp4` | 配音后的视频（口播混入） | 第④步一键链配音阶段 |
| `<成片输出目录>\srt\*.srt` | 字幕资产（服务端字级对齐 `.aligned.srt` 优先，重切段 `.srt` 次之） | 声音克隆完成/导出前 |
| `<成片输出目录>\bgm_ai\` | AI 生成 BGM | 第四步 BGM 生成 |
| `<缓存目录>\copy-montage\voice\*.wav`（同名 `.timing.json`、`.aligned.srt`） | 文案混剪每分镜的**整段克隆旁白**及字级时间轴/对齐字幕 | 文案混剪第③步批量克隆 |
| `<缓存目录>\copy-montage\sfx\*.wav` | 文案混剪音效（AI 生成 / 音效库匹配下载） | 第四步音效包装/智能音效匹配 |
| 剪映草稿箱目录 | 导出的剪映草稿工程（含 assets/、draft_content 等） | 「导出到剪映时间轴」 |

> ⚠️ 注意：`copy-montage\` 目录名为历史遗留（代码模块已更名 copywriting 前缀），**请勿手动重命名或移动**，否则已生成的旁白/音效资产会失联。清理缓存请使用「设置」页的缓存清理入口，不要直接删除 `outputs` 目录（成片交付物在内）。

## 6. 常见问题与处理

| 现象 | 原因与处理 |
| --- | --- |
| 提示「服务端不可达/请确认服务端可访问」 | 顶栏状态灯检查服务端；「设置」页确认服务端地址；服务端 GPU 服务（whisperx/TTS）启动需要时间 |
| 智能镜头分割失败 | 多为瞬时断线，界面会自动重试一次；仍失败按提示修正后重按「开始智能镜头分割」继续（已完成素材保留） |
| 批量克隆中途服务端无响应 | 点「停止克隆」（当前条完成后停止），恢复后再点「开始批量克隆」从断点续跑；单条重做用行内「重新生成」 |
| 某条视频关键词命中为 0 | ①检查产品资料是否关联关键词且与该条文案有交集；②系统已自动 LLM 补足至 ≥3 词，若仍为 0 说明兜底词与文案无交集；③在关键词标注面板手工选中文字右键标注 |
| 选择池出现重复素材 | 已按内容 MD5 标注「重复」，点条目右侧 × 删除多余条目 |
| 素材库型号输入卡死 | 已修复（候选按输入过滤并限 200 条）；如仍遇卡顿请更新客户端 |
| 预合成右键没有「重启合成」 | 已补齐；已合成方案首项即「重启合成」，待确认方案首项为「确认合成视频」 |
| 缩略图/预览黑屏 | 刷新页面即可（服务端地址预热已修复）；图片素材在池中以图片形式显示 |
| 导出报告提示某轨「缺少」 | 按报告逐轨核对：字幕缺少通常是该条未取到对齐 SRT；文字模板缺少是零命中（见上条关键词处理） |

## 7. 注意事项

1. 「清空混剪缓存」会删除 `montage_cache` 下全部任务目录（分割片段/成片输出），**原始素材不受影响**，但已生成分割片段需重新分割。
2. 分镜脚本以服务端脚本库为权威持久层；本地 localStorage 仅恢复界面状态（绑定组/声音/音效路径等）。
3. 文案混剪的剪映草稿为唯一交付形态，客户端不产出成片 mp4；需要成片请走智能混剪。
4. 批量任务（分割/克隆）进行中，关联的下游按钮（智能匹配/生成剪辑方案等）会按「素材池不完整不许合成」原则禁用，属预期防护。
5. 涉及服务端接口行为的描述以实测为准；服务端热更可能导致个别端点行为变化，异常时先看顶栏服务端状态与「设置 → 日志」。
