# 模块调用流程与客户端/服务端分工

- 版本：v2.1 | 更新：2026-08-12（由 v1.0 docx 迁移为 Markdown 权威版本，v2.1 按服务端 /guide 增补智能体编排/在线素材/数字人接口）
- 服务端统一地址：由 `studio/config/ai_config.json` 的 `compute_server_url` 配置（当前 `http://X.X.X.X:8000`）
- 接口契约权威来源：服务端 `/guide`（实际命名/参数/返回格式以 /guide 为准）

## 一、决策原则

1. **重模型 / 大 GPU / 大文件编解码 → 服务端**：避免客户端机器性能差异导致输出不一致，统一 10-bit/高画质转低画质等编码策略。
2. **交互 / 浏览 / 预览 / 本地数据管理 → 客户端**：保证响应速度和离线可用性。
3. **外部工具（Dreamina、Remotion）**：按部署情况决定，服务端有环境则优先迁服务端。
4. **轻量本地计算**（镜头去重哈希、时长探测、抽帧）可留客户端，避免网络往返。
