## 二、功能清单与现状核对

### 2.1 我的知识库（原 index 28）

**原功能**（[my_knowledge_page.py L1-9](file:///D:/Project/TinTin_AI_Agent_Main/studio/gui/my_knowledge_page.py#L1-L9)）：
- 以「风格化」为核心的三区布局：左风格化列表（按账号/内容类型/产品品类/行业垂类分组）→ 左下风格画像详情 → 右侧参考原始素材列表（双击看详情/播放/蒸馏内容）
- 工具栏：同步 / 导入 / 提炼
- 数据层：[my_knowledge_manager.py](file:///D:/Project/TinTin_AI_Agent_Main/studio/utils/my_knowledge_manager.py)（`to_prompt_text` 供文案创作引用）

**新端现状**：无独立页面；工作台上下文仅能选「分镜脚本」「素材」「产品」，未含风格化条目。

### 2.2 产品资料（原 index 27）

**原功能**（[product_library_page.py L1-12](file:///D:/Project/TinTin_AI_Agent_Main/studio/gui/product_library_page.py#L1-L12)）：
- 产品按「品类 → 品牌 → 型号」树状归类管理；服务端 `/api/product-library` 一键同步（服务端持 ERP 凭据，客户端不直连旺店通）
- 左侧树 + 关键词搜索；右侧表单手工归类/补充/删除
- 数据层：[product_library_manager.py](file:///D:/Project/TinTin_AI_Agent_Main/studio/utils/product_library_manager.py)（`to_prompt_text` 供文案创作）

**新端现状**：工作台「选择产品」弹窗已接 `GET /api/product-library/search`（[useWorkbenchPickers.ts L44](file:///d:/Project/TinTin_Client_Electron/desktop/renderer/src/composables/useWorkbenchPickers.ts#L44)），但无树状管理页。

### 2.3 产品文案创作（原 index 29）——归「媒体工具」

**原功能**（[product_script_page.py L1-11](file:///D:/Project/TinTin_AI_Agent_Main/studio/gui/product_script_page.py#L1-L11)）：
- 流程：选产品 → 查看性能参数&核心卖点 → 可选风格化条目（来自知识库）→ 附加提示词 → 一键生成文案；生成后可调风格 skill 改写
- 数据层：ProductLibraryManager + MyKnowledgeManager + LLMWorker

**新端现状**：无独立页面。

### 2.4 飞书脚本创作（原 index 19）——**不移植**

**原功能**（[ai_script_page.py](file:///D:/Project/TinTin_AI_Agent_Main/studio/gui/ai_script_page.py)）：
- 同步飞书选题（`FeishuSyncWorker`，依赖飞书四要素 app_id/secret/app_token/table_id，原 `[Feishu]` ini）
- 选题列表 → 选选题 → 生成 AI 文案（LLMWorker）→ 极限词检测 → 「前往分镜脚本创作」（带产品信息）
- 依赖飞书配置（原 S6，新端已在「设置 → 账号与登录」落地）

**新端现状**：飞书凭证已迁移至设置页；页面本体无。

### 2.5 分镜脚本创作（原 index 37）——归「媒体工具」

**原功能**（[storyboard_page.py L1-6](file:///D:/Project/TinTin_AI_Agent_Main/studio/gui/storyboard_page.py#L1-L6)）：
- 输入/接收视频文案 → 生成分镜脚本（竖向列表，每镜头含镜别/时长/音效/画面描述/旁白）
- 每镜头可引用素材（本地/即梦/MG/联网四类 Tab）→ 批量生成即梦镜头图 → 飞书同步
- 顶部：相似度自动绑定 + 画幅下拉（9:16/16:9/1:1）+ 保存分镜脚本（保存即刷新一键成片脚本列表）
- 数据层：`GET /api/storyboard/scripts`（新端选择器已接，[useWorkbenchPickers.ts L60](file:///d:/Project/TinTin_Client_Electron/desktop/renderer/src/composables/useWorkbenchPickers.ts#L60)）

**新端现状**：仅能选脚本入上下文；创作页本体无。

### 2.6 视频评价预测（原 index 34）

**原功能**（[hook_score_page.py L1-10](file:///D:/Project/TinTin_AI_Agent_Main/studio/gui/hook_score_page.py#L1-L10)）：
- 选投放平台 → 上传视频 → 抽取覆盖全片关键帧 → 视觉大模型按平台推荐逻辑预测表现（综合分+预测量级+多维评分+建议）

- 依赖：视觉模型（llm_vision_*）+ ffmpeg；数据层 [video_prediction_manager.py](file:///D:/Project/TinTin_AI_Agent_Main/studio/utils/video_prediction_manager.py)

**新端现状**：无。

### 2.7 视频营销检测（原 index 40）

**原功能**（[marketing_detect_page.py L1-6](file:///D:/Project/TinTin_AI_Agent_Main/studio/gui/marketing_detect_page.py#L1-L6)）：
- 视频关键帧 → 视觉大模型综合研判：是否营销/广告视频、推广品类、营销特征线索、改进建议
- 依赖：视觉模型 + ffmpeg

## 六、验收口径

1. 顶栏出现「运营工具」，位于工作台与媒体工具之间，高亮/切换行为与其他 Tab 一致（C6 切 Tab 防泄露）。
2. 每个工具卡点击进入对应工具页，右上角可返回卡片菜单（复用媒体工具 Launcher）。
3. 各工具业务流按原客户端流程执行（不按接口文档臆造）。
4. 与工作台共用的数据（产品/脚本/素材）同一服务端接口，无重复存储。
5. 单文件 ≤800 行，UI 层与业务逻辑解耦（composables/services 独立）。
