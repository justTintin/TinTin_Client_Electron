# 剪映轨道格式标准（2026-09-16 建立）

> **强制标准**（用户裁决 2026-09-16）：「剪映的轨道的所有格式的定义要形成标准，导出时根据此标准导出，而不是随便复制一个作为模板。」
> 本文是剪映草稿**轨道 / 片段 / 素材**字段的**唯一权威定义**；导出器实现必须与本文逐条对应。
> 依据来源：pyJianYingDraft 0.3.0（segment.py / track.py / local_materials.py / text_segment.py）+ 本机剪映 11.x 实测草稿 + 用户裁决。
> 变更流程（《工程规范铁律》铁律 9）：改标准 → 改导出器 → 单测钉住 → 登记《剪映互通整体方案》附录 H。

---

## 0. 总则

1. **一律按标准构造**：任何 track / segment / material 对象必须由导出器的**标准构造器**生成（见 §8 映射表）；**禁止手写段对象、禁止克隆其他草稿当模板**（2026-09-16 封面事故裁决）。
2. **最终裁判**：字段形状以本文为准；争议时以「本机剪映 11.x 实测能打开 + 轨道完整」为最终裁判。
3. **服务端直传段边界**：from-tasks 路径中来自服务端清单的段（视频/口播/BGM 等）由服务端生成，本地只做「窗口偏移 + 时长裁剪 + 路径绝对化」，**不重写字段**；若其格式违反本标准，按归因铁律上报，不在本地兜底。
4. **id 规范**：草稿内所有 id = **32 位小写 hex**（对照 uuid4().hex）；草稿目录名 = draft_name（命名规范见互通方案 §0.1）。
5. **时间单位**：微秒（us）整数。`target_timerange` = 段在时间轴的位置；`source_timerange` = 段在素材文件内部的起点/时长。
6. **静默不造假**：素材/预设缺失时跳过该段（不生成占位数据）；跳过必须可排障（日志或返回值）。

## 1. 草稿顶层结构

- 骨架 = `desktop/main/jianying-draft-template.js`（29 个顶层字段，来源 pyJianYingDraft 0.3.0 `assets/draft_content_template.json`）。
- **强制覆写**（导出时）：`id`（新 hex）、`name`（草稿名）、`duration`（总时长 us，§6）、`create_time`/`update_time`（秒）、`fps=30`、`canvas_config`（首视频宽高 + `ratio`：9:16 / 16:9 / 1:1）、`tracks`、`materials`。
- **版本三元组**（防剪映判「版本过低/已损坏」拒开）：`new_version='110.0.0'`、`version=360000`、`platform={app_id:3704, app_source:'lv', app_version:'5.9.0', os:'windows'}`、`last_modified_platform` 同 platform。
- 常量出处：`jianying-exporter.js` 顶部 `DRAFT_SCHEMA`。

## 2. 轨道（track）

构造器：`newTrack(type)`。字段仅以下 7 个（**track 本身不含 render_index**，render_index 挂在 segment 上，见 §3.5）：

| 字段 | 类型 | 标准值 | 说明 |
|---|---|---|---|
| id | string | `hexId()` | 32 位小写 hex |
| type | enum | `video` / `text` / `audio` / `sticker` / `effect` / `filter` | 轨道类型枚举 |
| attribute | int | `0` | 0=默认 1=静音 2=隐藏 4=锁定 |
| flag | int | `0` | 保留 |
| is_default_name | bool | `true` | 默认名标记 |
| name | string | `''` | 空 = 剪映显示「未命名轨道」 |
| segments | array | `[segment…]` | 见 §3 |

**导出器实际产出的轨道清单**（type 与产出函数）：

| 轨 | type | 产出函数（jianying-exporter.js / montage-final-ipc.js） |
|---|---|---|
| 主视频轨 | video | `exportMultiToDraft` §5 / `mergeJianyingManifests` |
| 字幕轨 | text | `appendSubtitleTrack`（经 `buildSubtitleSegment`） |
| 关键词花字轨 | text | `appendKeywordTrack(kind='fancy')` |
| 文字模板轨 | text | `appendTextTemplateSegments` |
| 花字事件轨 | text | `appendFancyEventTracks` |
| 口播轨 | audio | `exportMultiToDraft` §5（voiceClips）/ merge |
| 音效轨 | audio | `appendFancyEventTracks` |
| BGM 轨 | audio | `appendBgmTrack` |
| 贴纸轨 | sticker | `buildStickerTrackFromPreset` |
| 特效 | （不独立成轨） | `applyVideoEffect`：video_effects 素材挂主轨全部段 `extra_material_refs` |
| 转场 | （不独立成轨） | `buildTransitionMaterial`：挂「前一段」`extra_material_refs` |
| 滤镜 | **未实现（登记待做）** | — |

## 3. 片段（segment）

### 3.1 通用基类（`baseSegmentFields`）

| 字段 | 标准值 | 字段 | 标准值 |
|---|---|---|---|
| id | `hexId()` | enable_color_match_adjust | `false` |
| material_id | 素材 id（**必须存在**于 materials.*，§7-⑤ 校验） | enable_color_wheels | `true` |
| target_timerange | `{start, duration}` us | enable_lut | `true` |
| enable_adjust | `true` | enable_smart_color_adjust | `false` |
| enable_color_correct_adjust | `false` | last_nonzero_volume | `1.0` |
| enable_color_curves | `true` | reverse | `false` |
| track_attribute | `0` | common_keyframes | `[]` |
| track_render_index | `0` | keyframe_refs | `[]` |
| visible | `true` | | |

### 3.2 视觉段附加（`visualSegmentFields`，视频/贴纸/文本段）

```json
{
  "clip": {
    "alpha": 1.0,
    "flip": { "horizontal": false, "vertical": false },
    "rotation": 0.0,
    "scale": { "x": 1.0, "y": 1.0 },
    "transform": { "x": 0.0, "y": 0.0 }
  },
  "uniform_scale": { "on": true, "value": 1.0 }
}
```

- **字幕段**：`clip.transform = {x: 0, y: -0.8}`（`SUBTITLE_TRANSFORM_Y`；pyJianYingDraft `ClipSettings` 官方口径，单位=半画布，y 负=向下）。
- **贴纸段**：`clip` 由 R2 公式换算（设计画布 720×720、y 向上）。
- **视频段**：另加 `hdr_settings = {intensity: 1.0, mode: 1, nits: 1000}`。

### 3.3 媒体段附加（`mediaSegmentFields`）

| 字段 | 标准值 |
|---|---|
| source_timerange | `{start: 0, duration: dur}`（与 target 同步裁剪） |
| speed | `1.0` |
| volume | `1.0`（有口播的素材段 `0`，见 §6） |
| extra_material_refs | `[speedId, …]`（speed 素材 id 必须存在，§7-⑤） |
| is_tone_modify | `false` |

### 3.4 音频段附加

`source_timerange` / `speed` / `volume` / `extra_material_refs: [speedId]` / `is_tone_modify: false` / `clip: null` / `hdr_settings: null`。

### 3.5 render_index（段级）

按轨道顺序统一赋值：`draft_content_tracks_render_index(tracks)` —— 第 N 条轨的全部段 `seg.render_index = N`（0 起）。**唯一实现**，禁止逐段手写。

## 4. 素材（materials.*）

### 4.1 videos（`videoMaterialFields`）

`audio_fade:null`、`category_id:''`、`category_name:'local'`、`check_flag:63487`、`crop`（四角全幅 `{upper_left_x:0, upper_left_y:0, upper_right_x:1, upper_right_y:0, lower_left_x:0, lower_left_y:1, lower_right_x:1, lower_right_y:1}`）、`crop_ratio:'free'`、`crop_scale:1.0`、`duration`、`height`、`id`、`local_material_id:''`、`material_id`（=id）、`material_name`、`media_path:''`、`path`（绝对路径，正斜杠）、`type:'video'`、`width`。

### 4.2 audios（`audioMaterialFields`）

`app_id:0`、`category_id:''`、`category_name:'local'`、`check_flag:3`、`copyright_limit_type:'none'`、`duration`、`effect_id:''`、`formula_id:''`、`id`、`local_material_id:''`、`music_id:''`、`name`（文件名）、`path`、`source_platform:0`、`type:'extract_music'`、`wave_points:[]`。

### 4.3 texts（`textMaterial`）

| 字段 | 标准值 |
|---|---|
| id | `hexId()` |
| content | JSON **字符串**（结构见下） |
| typesetting | `0` |
| alignment | `0`=左 `1`=居中 `2`=右（字幕=1，`SUBTITLE_ALIGNMENT`） |
| letter_spacing | `0` |
| line_spacing | `0.02` |
| line_feed | `1` |
| force_apply_line_max_width | `false` |
| check_flag | `7` |
| type | `'text'` |
| global_alpha | `1.0` |

content JSON 结构：
```json
{
  "styles": [{
    "fill": { "alpha": 1.0, "content": { "render_type": "solid", "solid": { "alpha": 1.0, "color": [r, g, b] } } },
    "range": [0, 文本长度],
    "size": 8.0, "bold": false, "italic": false, "underline": false, "strokes": [],
    "effectStyle": { "id": "花字效果id", "path": "C:" }
  }],
  "text": "文本内容"
}
```
（`color` = 0-1 浮点三元组；`effectStyle` 仅花字/带效果文本有。）

### 4.4 stickers（`stickerMaterial`）

`id`、`resource_id`、`sticker_id`（=resource_id）、`source_platform:1`、`type:'sticker'`。

### 4.5 video_effects（`videoEffectMaterial`）

`apply_target_type:0`、`category_id:''`、`category_name:''`、`effect_id`、`id`、`name`、`path:''`、`platform:'all'`、`resource_id`、`source_platform:1`、`type:'video_effect'`、`value:1.0`、`request_id:''`、`keyframes:[]`。

### 4.6 effects（花字）

- 关键词花字（`textEffectMaterial`）：`apply_target_type:0`、`effect_id`、`id`、`resource_id`、`type:'text_effect'`、`value:1.0`、`source_platform:1`。
- 模板花字（`templateFlowerEffectMaterial`）：`id`、`resource_id`、`type:'text_effect'`、`sub_type:'none'`、`path`、`source_platform:1`、`multi_language_current:''`、`beauty_face_auto_retouch_info:{}`。

### 4.7 material_animations（入场/循环动画）

- 常规文本（`textIntroAnimationMaterial`）：`id`、`type:'sticker_animation'`、`multi_language_current:'none'`、`animations:[{anim_adjust_params:null, platform:'all', panel:'', material_type:'sticker', name, id:效果id, type:'in', resource_id, start:0, duration:min(动画时长, 段时长)}]`。
- 模板实例（`templateAnimMaterial`）：`id`、`type:'sticker_animation'`、`animations:[{id:'', type:'in'|'loop', duration:500000|800000, path, resource_id, source_platform:1, material_type:'sticker'}]`。

### 4.8 speeds（`speedMaterial`）

`curve_speed:null`、`id`、`mode:0`、`speed`、`type:'speed'`。**每个媒体/文本段必须有一个对应 speed 素材**（`extra_material_refs` 引用）。

### 4.9 transitions（`buildTransitionMaterial`）

`category_id:''`、`category_name:''`、`duration`、`effect_id`、`id`、`is_overlap`、`name`、`platform:'all'`、`resource_id`、`type:'transition'`。挂法：materials.transitions + **前一段** 的 `extra_material_refs`。

## 5. 文字模板三件套（剪映原生模板引用式）

面向「零渲染保真」：由 `buildTemplateClipTrio(preset, phrase)` 从本机 `.textpreset` 机械重排生成（结构范本：王晗雨解密草稿同构实证）：

1. `materials.text_templates[]` ← preset.effect/resources/paragraphs[0].attach_info/elements（sticker）——字段清单：`id`、`version`、`effect_id`、`resource_id`、`name`、`type:'text_template'`、`path`（artistEffect 缓存）、`category_id`、`category_name`、`source_platform:1`、`resources[]`、`text_info_resources[]`、`non_text_info_resources[]`、`aigc_config`、`request_id`、`origin_word_info`、`current_word_info`、`preview_time:0.1`、`ai_generate_task_info`。
2. `materials.texts[]` ← preset.paragraphs[0].content（仅替换 text + 对齐 range）。**关键绑定键：`texts.name = 预设 text_name`**（随机 id 时剪映回退渲染模板默认文字，2026-09-15 真机定位）。
3. 文字轨 segment ← `material_id` 指向 text_templates 实例 id；`extra_material_refs = [speed, 花字效果, 动画素材]`（按范本顺序）。

模板缺失（preset 不存在/结构不全）→ 跳过不造假；模板轨失败不阻断导出（字幕轨仍在）。

## 6. 内容时长与窗口口径

- `content.duration` = 各任务窗口累计 + 片段间半秒间隔（`VIDEO_GAP_US=500000`，最后一个不加）。
- **全轨窗口口径**（2026-09-16 用户实测定稿）：所有轨道按「任务窗口」定位，窗口 = 前序任务 content.duration 累计 + 0.5s 间隔。字幕 cue/模板/花字/音效为任务内局部系 + 窗口起点偏移。
- 有口播的素材段 `volume=0`（配音替换原声）；无口播保留原声。

## 7. 合规校验（导出「成功」的硬判据）

`verifyDraftFolder({draftFolder, expectedAssetCount})`：

| # | 检查项 | 不通过后果 |
|---|---|---|
| ① | `draft_content.json` / `draft_meta_info.json` 可解析 | 明确报错 |
| ② | 轨道非空 | 明确报错 |
| ③ | 所有素材 `path` 磁盘存在 | 明确报错（最多列 10 条） |
| ④ | assets 文件数 ≥ 清单数（expectedAssetCount>0 时） | 明确报错 |
| ⑤ | **段 `material_id` 无悬空**（必须在 materials.* 中存在，2026-09-16 新增） | 明确报错（`dangling` 计数） |

返回：`{ ok, trackCounts, pathRefs, missing, dangling, assetFiles, problems }`。不通过 → 导出 `success:false` 并明列问题。
