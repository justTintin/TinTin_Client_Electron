## 四、拆分模式（定案）

**provide/inject**（非 props/emits——230 键 prop 钻透不可维护，且模板需逐字搬迁）：

```
VideoMontage.vue（Shell，目标 ≤650 行）
  const s = useVideoMontage()
  provide(montageKey, { s, step, go, vdLeftStyle, onSplitDown, previewAspect,
                        fancyCustomPreviewStyle, ...跨面板只读项 })
  模板保留：根容器 + 4 个 <MontageStepNPanel /> + ns-section + VideoPreview + 页尾状态条
MontageStep1Panel.vue … MontageStep4Panel.vue
  script：const { s, step, go, … } = inject(montageKey)!
          const { 本面板模板用到的键 } = s   ← 解构回原名 ⇒ 模板逐字搬迁零改动
  template：原面板区块逐字搬迁
  style：本面板样式段搬迁；共享类在 Shell 用 :deep() 或提公共 css
```

- **铁律**：模板与样式逐字搬迁，禁止顺手改类名/绑定表达式；键名零改动。
- 注入对象类型：`ReturnType<typeof useVideoMontage>` + Shell 本地项的组合接口。
- 8 个弹窗/菜单随所属面板搬迁（teleport 到 body 不受组件位置影响）。
- 样式策略：共享类（.card/.sec-label/.bottom-status/.ctx-*/.vd-unified/.vd-split/.pbar 等）
  保留 Shell 并对子面板生效需 `:deep()` ——或更稳：共享类迁入各面板（少量重复，机械可控），
  面板私有类随面板走。执行时以「样式段逐块 grep 使用方」为准。
