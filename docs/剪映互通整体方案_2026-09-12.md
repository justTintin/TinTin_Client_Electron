### 概念对齐（2026-09-12 用户裁决，防止再混淆）

| 概念 | 定义 |
|---|---|
| **文字模板** | 剪映直接提供的成品模板（花字库下的花字与图标包）：花字样式+动画+装饰图标封装在一起的**原子资产**，拖入轨道直接可用。其动画**封装在花字效果资源内部**，不是独立动画素材 |
| 文本动画（独立类别） | 文本片段上叠加的入场/出场/循环动画，与转场动画、贴纸动画各自成体系。本期仅作字幕轨入场动画的**可选降级能力**，不用于文字模板 |
| 本期「渲染」的对齐口径 | 服务端合成 = textfx 按 template.html 渲染（权威）；本地合成 = 同源近似（颜色/装饰图标精确、动画近似），像素级一致方案见 §5 R3 |

### 0.0 单一数据源裁决（2026-09-13 用户裁决，最高优先级）

**剪映同步的所有模板/素材，以服务端为唯一数据源（Single Source of Truth）**：

```
剪映（本机）──「从剪映同步」（仅上传）──▶ 服务端模板库（唯一权威）──下发──▶ 客户端展示（缓存）
```

- 客户端各卡片（剪映模板/花字库/文字模板/音频…）的数据源 = **服务端接口**（GET /text_templates/templates、GET /audio/library 等），不是本地剪映目录
- 本地剪映目录扫描**只出现在「从剪映同步」弹窗**（选择要上传的类目与条目）
- 同步状态由服务端数据天然承载（在库=已同步）；删除=删服务端条目，客户端刷新即消失
- 离线时客户端展示服务端最后下发的缓存，不回退到本地扫描

### 0.1 分类字典与命名规范（强制，2026-09-12 用户裁决）

> 以**剪映顶部菜单体系为唯一术语来源**；服务端 category 与本项目代码/文档命名一律按下表对齐，新增能力先登记此表再动工。

| 剪映菜单 | 子类 | 草稿 schema 落点 | 服务端落点 | 本项目命名 | 期 |
|---|---|---|---|---|---|
| 素材（媒体） | 本地/素材库视频图片 | materials.videos / images | —（不经模板库） | 视频轨 videoTrack | 已有 |
| 音频 | 音乐/音效/配音 | materials.audios | /audio/bgm、/voice/* | BGM 轨 / 配音 voice | 已有 |
| 文本 | 总类（下含三子类） | materials.texts（type: text \| subtitle） | /text_templates、/fancy/templates | 文本 text | 本期 |
| └ 花字 | 样式+动画封装的花字效果 | content.effectStyle + materials.effects（type:'text_effect'） | fancy（`resources/fancy/templates/jy_*.json`） | 花字 fancy | 本期 |
| └ **文字模板** | 成品模板包（花字+装饰图标+动画，原子资产） | 同花字 + 装饰图标（包内 elements，存储格式 type:'sticker'） | `/text_templates` zip，id=`jy_<剪映资源id>`，category=场景词 | **文字模板 textTemplate（本期主角）** | **本期** |
| └ 智能文本 | 识别/输入生成的字幕 | text material type:'subtitle' | subtitle_srt / subtitle_srt_file | 字幕 caption | 本期 |
| 贴纸 | 独立贴纸素材 | materials.stickers（StickerSegment：resource_id/sticker_id） | — | 贴纸 sticker | **二期** |
| 特效 | 画面特效 | materials.video_effects / effects | — | 特效 effect | **二期** |
| 转场 | 片段转场 | materials.transitions | — | 转场 transition | 基础已有；动画化二期 |
| 字幕 | 由智能文本生成 | 同「智能文本」 | 同「智能文本」 | 同上 | 本期 |

**命名规则**：
1. 文档/UI/注释术语以剪映菜单名为准：文字模板、花字、字幕、贴纸、特效、转场；禁止混称（文字模板≠贴纸≠特效；花字不叫特效）。
2. **装饰图标**＝文字模板包内部的组成元素（textpreset.elements，存储格式 type:'sticker' 只是包内格式），**与剪映「贴纸」菜单类别无关**——涉及包内图标时一律写「装饰图标」。
3. **category = 类目（层级属性），tags = 场景标签（检索属性），两者分离（2026-09-12 用户裁决修正）**：好物种草/美食/穿搭/科技数码/综艺/强调/热门 是**场景标签（tag 语义，可多枚举、开放扩展）**，不是层级类目；文字模板的**类目**来自剪映原始 category_name（文字模板/热门/最新…，可随剪映更新扩展，开放集合）。正确形态：`category=文字模板`（类目）+ `tags=美食,剪映同步,source=jianying-cache`（场景+溯源标签）。**过渡态**（服务端当前把场景词放 category 并硬校验 7 值枚举）：客户端 category 填合法场景词保证入库、原始类目移入 description 留痕——已报服务端按本条调整（category 收类目开放集合 / 场景词移 tags），改后一次切齐。资产类型由 **id 前缀**承载：`jy_` = 剪映文字模板同步。
4. 草稿 schema 类目名（texts/stickers/effects/transitions/material_animations/text_templates…）保持剪映原名，不自拟。
5. 代码内部命名对照：fancy=花字、textTemplate=文字模板、caption/subtitle=字幕、transition=转场、sticker=贴纸（仅指菜单类别，二期）。

## 2. 本期链路与数据流（文字模板闭环）

```
剪映侧（明文三件套，免解密）
  ├─ key_value.json（草稿/预设所用模板 resource_id 清单）
  ├─ Presets/Text_V2/*.textpreset（模板包：effect 引用+文本样式+贴纸 elements+resources）
  └─ Cache/artistEffect/<rid>/（效果素材本机缓存：贴纸 PNG、动画 prefab/lua）
        │  ① 提取（客户端解析器，纯逻辑）
        ▼
  服务端模板库 POST /text_templates/templates（zip：template.html + meta.json）
  ├─ template.html：文字（CSS 变量色/字号）+ 贴纸 PNG base64 内联 + CSS 动画近似
  └─ meta.json：id=jy_<resource_id> / name / category / description(含来源版本三元组) / variables
        │  ② 服务端合成（现有）：concat 命中 → textfx 渲染烧制
        │  ③ 客户端识别（现有）：GET 列表 → Step4 下拉（自动出现）
        │  ④ 本地合成（R3）：同源渲染
        ▼  方案A：drawtext+overlay 近似（离线可用）
           方案B：叠加服务端「参数化渲染」输出的全分辨率透明 WebM（与合成同源同缓存，像素级一致；
                  服务端渲染器/缓存本就支持任意尺寸/帧率/时长/变量，只差参数化接口 ~0.5d；
                  ⚠️ 不得使用 preview.webm——那是 540×960 演示预览，非方案B素材）
  ⑤ 导出剪映草稿（现有 v2）：文本挂 effectStyle + materials.effects → 剪映原生渲染
```

**版本三元组契约**（§6.3 沿用）：剪映应用版本（11.5.5.14461）/ 草稿 schema（new_version 110.0.0·导出方）/ textpreset version（5）。同步包记入 meta description；导出器 `DRAFT_SCHEMA` 常量随返回值下发。

## 5. 关键实现要点（本期）

1. **文字模板素材的明文三件套**（免解密，实测）：`key_value.json`（模板 resource_id 清单）+ `Presets/Text_V2/*.textpreset`（模板包，version=5）+ `Cache/artistEffect/<rid>/`（贴纸 PNG、动画 prefab）。三者按 `effect.resource_id` 对齐。
2. **动画封装在花字效果资源内部**（.textpreset 无 animation 字段，实测证实）——剪映按 resource_id 自解析渲染，客户端/服务端不需要（也无法）搬运动画本体。
3. **装饰图标内联**：文字模板包内装饰图标 PNG 体积小（实测 1.6~18KB），base64 内联进 template.html 即可满足服务端 zip 格式（template.html+meta.json），**不依赖 S2 资源承载扩展**。
4. **上传幂等**：同 id upsert；id 规范 `jy_<剪映资源id>` 保证与剪映资源可追溯。
5. **本地渲染方案选择**：方案A（近似）先行保底；方案B = 服务端新增**参数化渲染接口**（尺寸/帧率/时长/变量可参数化，约 0.5 天）——渲染器与缓存本就支持任意参数、产物带 alpha、与合成同源同缓存（像素级一致），无需新渲染技术。**`preview.webm`（540×960 演示预览）禁止用作方案B素材**，避免错误的像素一致预期。
