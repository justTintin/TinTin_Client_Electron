# 视频下载

## 用途
用户提供抖音/B站/YouTube 等视频链接时，在**客户端素材浏览器**（Electron）中下载该视频，
下载产物经素材库入库后取得素材 ID，供「仿爆款」拆解/复刻使用。

## 执行步骤
1. 确认用户提供的链接（抖音 / B站 / YouTube / 快手 / 小红书等）
2. 打开客户端素材浏览器并定位到对应平台页面（下载目录指向「爆款仿制」专属目录）
3. 提示用户在素材浏览器中完成下载（嗅探/保存），下载不走服务端
4. 素材入库后，让用户把素材 ID 填入「仿爆款」对话框继续拆解

## 注意事项
- 下载一律由客户端素材浏览器完成，**不要**要求服务端下载
- 抖音未登录/触发风控时，先引导用户扫码/滑块验证
