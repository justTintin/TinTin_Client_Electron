## 0. 参考仓库定位（本次新增）

**pyJianYingDraft**（https://github.com/GuanYixuan/pyJianYingDraft ）
- 一句话：Python 程序化生成、编辑、导出**剪映（JianYing / CapCut）草稿**，用于搭建全自动视频剪辑/混剪流水线。
- 与本项目花字的**对应点**（官方功能清单中的两项）：
  1. **文本及字幕 → 文字气泡效果和花字效果**：可在草稿中把文本叠加剪映原生花字效果。
  2. **模板模式 → 提取模板中出现的贴纸/气泡/花字等元信息**：通过 `inspect_material` 提取草稿中花字效果的 `resource_id` / `Effect id`。
- **为什么加入**：本项目花字模板携带 `jy_effect_id`（剪映原生花字效果 id，`source: jy_key_value`），标记了一条**「剪映草稿通道」**。该库正是这条路线的参考实现/工具：可用 `DraftFolder` 加载/复制含花字的模板草稿、`inspect_material` 提取花字效果元数据、`TextSegment` 生成带花字效果的文本片段。

> ⚠️ 当前客户端花字**实际走 ffmpeg 直出通道**（见 §6），剪映草稿通道为**预留**，`jy_effect_id` 仅随模板携带、未被客户端烧制逻辑消费。两者关系见 §9。

## 1. 概述：什么是「花字」

电商短视频里叠加在画面上、带**描边/渐变/阴影 + 入场动画 + 出现音效**的**强调卖点词**（如「199元超值」）。本项目把「花字」作为智能混剪 Step3「口播配音」的一个可选项，在视频替换原声时一并烧制。

### 两条实现通道

| 通道 | 说明 | 当前状态 |
|---|---|---|
| **本地直出通道** | 主进程 ffmpeg `drawtext` 把花字按 drawtext 样式串直接烧进视频 | ✅ **当前生效** |
| **剪映草稿通道** | 用 `jy_effect_id` 借助剪映原生花字效果生成草稿（pyJianYingDraft） | 🔜 预留 |


## 4. 模板 JSON Schema

来源 `fancy-templates.js` 头注释 + 实际模板文件（如 `jy_7495312625169911065.json`）。

| 字段 | 类型 | 说明 |
|---|---|---|
| `template_id` | string | 模板标识（`jy_<效果id>` / `gold_pop`） |
| `name` | string | 中文名（如「综艺风蓝色立体描边花字」） |
| `style` | string | **drawtext 样式串**（本地直出通道），如 `fontcolor=0x40A0FF:borderw=4:bordercolor=0x003080:shadowx=2:shadowy=2:shadowcolor=0x000000@0.8` |
| `jy_effect_id` | string? | 剪映草稿通道花字效果 id（可空） |
| `jy_intro_anim` | string? | 剪映入场动画名（可空，映射成 fade/rise/slide/pop/none） |
| `sound` | object? | 出现音效：`{ "file": "sfx/xxx.mp3", "gain_db": -6 }`（file 相对 fancy 根目录；可空） |
| `timing` | string | 时机（如 `subtitle_sync` / `uniform`） |
| `category` | string? | 分类（如「🍉夏日」） |
| `is_vip` | boolean? | 是否会员模板 |
| `source` | string? | 来源（`jy_key_value` = 剪映 key_value） |
| `anim` | string? | 显式入场动画（优先于 jy_intro_anim 语义映射） |

**示例**（`resources/fancy/templates/jy_7495312625169911065.json`）：

```json
{
  "template_id": "jy_7495312625169911065",
  "name": "综艺风蓝色立体描边花字",
  "style": "fontcolor=0x40A0FF:borderw=4:bordercolor=0x003080:shadowx=2:shadowy=2:shadowcolor=0x000000@0.8",
  "jy_effect_id": "7495312625169911065",
  "jy_intro_anim": "",
  "sound": null,
  "timing": "subtitle_sync",
  "category": "🍉夏日",
  "is_vip": true,
  "source": "jy_key_value",
  "anim": "rise"
}
```

## 5. 纯函数层关键逻辑（`desktop/main/voice-tts-logic.js`）

### 5.1 卖点提取
- `parseFancyWords`（L293）：全角逗号归一 → 半角逗号拆分 → 去空白。
- `extractFancyWordsInLine` / `extractFancyWordsFromText`（L383/L418）：**优先级 价格 > 数字参数 > 关键词**；单条截断 `FANCY_MAX_LEN=10`，每条视频上限 `FANCY_MAX_PER_VIDEO=3`。

### 5.2 出现位置（剪映安全框对齐，L347）
`FANCY_POSITIONS` 8 个位置全部落在剪映竖屏(9:16)默认安全框内（`SAFE_X=0.08 / SAFE_TOP=0.08 / SAFE_BOTTOM=0.10`，避开平台 UI）：`upper_middle`(默认)/`top`/`center`/`bottom`/`top_left`/`top_right`/`bottom_left`/`bottom_right`。x/y 为 drawtext 表达式。

### 5.3 入场动画映射（L550-568）
`getFancyAnim`：`anim` 显式优先；否则按 `jy_intro_anim` 关键词映射（`FANCY_ANIM_KEYWORDS`）→`fade/rise/slide/pop/none`；未识别/空 → `fade`。

### 5.4 花字事件构建（L573-597）
`buildFancyEvents`：逐字幕行提取卖点（quota 递减 `FANCY_MAX_PER_VIDEO`），跟随该行时间窗**提前 `FANCY_LEAD_SEC=0.3s` 出现**、该行字幕结束消失；行内多卖点均分时间窗；最后 `resolveFancyOverlaps` 消解重叠。

### 5.5 样式预设（L300）
`FANCY_STYLES`：gold/red/blue/purple/neon_green/white_outline/yellow_red 7 套内置 drawtext 样式串（fontcolor+border+shadow）。

### 5.6 转义（L318）
`escapeDrawText`：`\ `、`'`、`:`、`,` 转义，避免破坏 drawtext 语法。

## 6. 烧制实现（`voice:dubVideos` → `buildDubFFmpegArgs`，L764-839）

- **开关**：`o.fancyText` 且 `o.fancyText && fancyEvents.length` 才叠加（内容自动从口播文案提取卖点，无卖点行不出现）。
- **drawtext 结构**（L807-814）：
  ```
  drawtext=fontfile='<字体>':text='<词>':fontsize=h*0.08:<styleStr>:
          x=<位置/动画表达式>:y=<位置/动画表达式>:
          enable='between(t,<start>,<end>)':<动画>
  ```
- **模板优先**（L776）：选了花字模板时 `styleStr = 模板.style`；未选回退 `FANCY_STYLES[o.fancyStyle] || gold`（=自定义样式）。
- **位置/动画**（L788-806）：`fade`（alpha 淡入）、`rise`（淡入+上移）、`slide`（淡入+右入）、`pop`（淡入+缩放抖动）；`alpha`/`x`/`y` 用 `if(lt(t,s))` 的时间表达式，`s=出现时刻`。
- **字体**（L459-461 / L772）：`msyhbd.ttc` → `msyh.ttc` → `msyh`。
- **音效混入**（L815-822 / L838-839）：模板音效路径经 `FT.getFancySoundPath(tpl)` 主进程预解析（缺失为空→不混）；`o.__soundSpecs` → `adelay`（对齐花字出现毫秒）+ `amix` 混入配音，`normalize=0` 防拉低人声；必须加在 `atempo` 之后。

## 7. 渲染层 UI（`renderer/src/composables/useVideoMontage.ts`）

- `loadFancyTemplates`（L2011）：`fancyListTemplates` → 回填 `templates`+`previews`；缺失预览随后调 `fancyEnsurePreviews` 后台 ffmpeg 补齐后刷新；失败不阻断页面。
- `selectedFancyTemplate` computed（L2030）：勾选且选中模板时返回模板 dict（**模板优先**，样式/动画/音效以模板为准）；返回 `null` = 自定义样式。
- `previewFancyWords`（L2036）：**花字预览弹窗**——按每个视频当前文案用渲染层 `extractFancyWordsFromText` 列出将生成的花字（未勾选花字则注明仅预览不生效）。

## 9. 两条通道的关系与扩展方向

- **本地直出**是当前唯一生效通道：模板的 `style`（drawtext 串）直接被 ffmpeg 消费；`jy_effect_id`/`jy_intro_anim` 只是模板里**携带的元数据**（`getFancyAnim` 用 `jy_intro_anim` 做语义映射，`jy_effect_id` 未被消费）。
- **剪映草稿通道（预留）**：若要让花字还原成剪映原生效果，需走 pyJianYingDraft 路线 —— 用 `DraftFolder` 加载/复制含花字的模板草稿，`inspect_material` 提取花字效果元数据（得到 `jy_effect_id` 对应引用），`TextSegment` 生成带花字效果的文本并 `save()`；`jy_effect_id` 即这里要对接的资源/效果 id。
- 优缺点对比：本地直出**无需剪映、纯 ffmpeg 可控、适合批量**，但只能用 drawtext 表达近似效果；剪映草稿通道能还原原生花字，但依赖剪映客户端 + 导入导出，批量导出受剪映版本限制（pyJianYingDraft 中 6.x 支持、新版受限）。
