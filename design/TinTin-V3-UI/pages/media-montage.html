附录 B · 铁律待验证矛盾点

矛盾点说明
/montage/split 响应逐镜字段shot_type / product / model / resolution 在 openapi 为空 schema（零文档）。 本端宽容解析（有则显示、无则 —）；「产品/型号」列多数为空。需验证服务端逐镜分析是否返回。
/audio/gen/bgm 契约 description中文 style/mood 枚举与原客户端实现（{prompt, style, duration} 无 mood）矛盾，不采信。
/api/product-library/clients/{mid}/items/{id}响应空 schema，实测无 features/selling_points；已改走 /grouped 全量缓存直取（工作台弹窗用 /search 实证条目自带字段）。

附录 C · 移植方法论（本次固化）

界面 + 代码双参考；界面一比一移植；功能跟着界面走。
① 界面源 = 原客户端 view/page 的 setup_ui（控件清单、布局、文案、默认值、tooltip、下拉选项逐字逐项）； ② 行为源 = controller/worker/client 调用链；③ 契约 = openapi 仅作端点参考，字段以原客户端实际调用为准； ④ 原版界面没有的功能不私自加，架构补位功能必须标注「本端扩展」并列入待裁决； ⑤ 交付前出逐控件对照表自查；⑥ UI 规格落盘本目录设计稿。
